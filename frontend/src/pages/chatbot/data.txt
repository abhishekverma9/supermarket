Topic: Agentic RAG
Question: What is agentic RAG?
Answer: Agentic RAG, or Retrieval-Augmented Generation with Agents, is an advanced system that uses autonomous AI 'agents' to handle complex queries. Unlike standard RAG which just retrieves and answers, an agentic system can plan, reason, and use multiple tools. For example, a query router agent might first decide *if* it needs to search a vector database, query a SQL database, or just chat. Other agents can then execute those tasks, validate information, or even ask clarifying questions.

Topic: CRAG
Question: Explain CRAG
Answer: CRAG stands for Corrective Retrieval-Augmented Generation. It's an enhanced RAG model designed to improve the accuracy of retrieved information. A key feature of CRAG is its 'retrieval evaluator.' This component assesses the relevance of documents retrieved for a query. If the documents are found to be irrelevant or low-quality, CRAG will automatically trigger a new, often rephrased, search to find better information. This corrective loop helps prevent hallucinations and ensures the final answer is based on the most accurate context.

Topic: Shopping Mart Database Schema
Schema: Our supermarket database consists of three main tables:
1.  **Products**: Contains product information.
    * Columns: product_id (INTEGER, Primary Key), product_name (TEXT), category (TEXT), price (REAL), stock_quantity (INTEGER)
2.  **Customers**: Stores customer details.
    * Columns: customer_id (INTEGER, Primary Key), first_name (TEXT), last_name (TEXT), email (TEXT), join_date (TEXT)
3.  **Orders**: Links products and customers.
    * Columns: order_id (INTEGER, Primary Key), customer_id (INTEGER, Foreign Key to Customers), order_date (TEXT), total_amount (REAL)

Common Questions about the Shopping Mart:
Question: How do I find the total number of products in the 'Dairy' category?
Answer: You would need to query the 'Products' table. A possible SQL query would be: SELECT COUNT(*) FROM Products WHERE category = 'Dairy';
Question: How can I check the stock level for 'Organic Milk'?
Answer: You would query the 'Products' table for the stock_quantity. Example: SELECT stock_quantity FROM Products WHERE product_name = 'Organic Milk';
